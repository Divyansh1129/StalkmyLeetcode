# Deployment and persistence

Run locally with `npm install`, set environment values from `.env.example`, then run `npm start` and open `http://localhost:3000`.

For Vercel, set `MONGODB_URI`, `ADMIN_PASSWORD`, and `CRON_SECRET` in Project Settings → Environment Variables. Optional event integrations use `DISCORD_WEBHOOK_URL`, `TELEGRAM_BOT_TOKEN`, and `TELEGRAM_CHAT_ID`; optional browser push uses the `VAPID_*` values generated by `npx web-push generate-vapid-keys`. `TIMEZONE` defaults to Asia/Kolkata. See [README.md](README.md) for descriptions and setup steps.

`vercel.json` routes the static public files through Express and schedules sync at 04:00 UTC and streak reminders at 15:00 UTC (20:30 IST). Vercel Hobby supports daily schedules; configure cron-job.org to call `/api/cron/sync` with `Authorization: Bearer <CRON_SECRET>` for a 15-minute cadence.

Without `MONGODB_URI`, all server data falls back to process memory and is not durable or shared across serverless instances. MongoDB Atlas is optional for local UI work and required for shared persistent features. Admin writes require `ADMIN_PASSWORD`; the browser receives only a signed, HttpOnly session cookie.
